 # CreditWise Loan System

## Project Overview

CreditWise Loan System is a Machine Learning project designed to predict loan approval status based on applicant information. The project analyzes historical loan data, performs data preprocessing, and trains multiple classification models to determine whether a loan application is likely to be approved.

---

## Objectives

- Analyze loan applicant data
- Perform data cleaning and preprocessing
- Train machine learning classification models
- Compare model performance
- Predict loan approval status

---

## Dataset Features

The dataset contains applicant-related information such as:

- Gender
- Marital Status
- Dependents
- Education
- Self Employment Status
- Applicant Income
- Coapplicant Income
- Loan Amount
- Loan Amount Term
- Credit History
- Property Area
- Loan Status

## Machine Learning Algorithms

The following classification algorithms were implemented and compared:

### Logistic Regression
Used as a baseline classification model for loan approval prediction.

### K-Nearest Neighbors (KNN)
Classifies applicants based on similarities with neighboring data points.

### Naive Bayes
Probabilistic classifier based on Bayes' theorem.
